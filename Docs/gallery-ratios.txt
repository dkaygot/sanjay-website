**Notes for building it**

1. **Why some galleries aren't perfectly even.** In Theyyam, Holi and Taj Mahal, the leftover difference is smaller than a single landscape photo. With so few portraits, no arrangement gets closer without scrambling the order.
2. **Rows are reading order, not straight lines.** In a masonry layout each column stacks on its own, so a table "row" only shows which images sit near each other.
3. **Place images column by column.** CSS `column-count: 3` fills the first column top to bottom, then the next, which would ignore this plan. Use three separate column containers (for example, three flex-column `div`s) and put each column's images into its own container.
4. **Spacing between images adds height.** Every gap adds a little to a column, so a column with more images grows a bit more. In Holi, Column 1 has 11 images versus 8, so it will end up slightly taller than the numbers suggest. Keeping gaps small (8–12px) limits this.
5. **Numbering gaps.** Travel has no 23.jpg, and Theyyam jumps from 7 to 13. That may be intentional, but it's worth checking that no files went missing in the transfer.
